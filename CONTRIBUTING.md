# Contributing — private Beta

MM Zidoo Sync is a private project. Licensing and outside contribution terms remain undecided. Do not invite outside contributions before the owner resolves those terms.

The native Beta has production synchronization enabled behind validation, exporter verification and plan review. Use synthetic fixtures and simulated devices for development; live device operations require their separately reviewed scope.

Keep the current application name, MMZidooSync executable name, Beta metadata and About/Help description consistent. Preserve historical release records and immutable local reference files. Update current status, known bugs and relevant documentation with behavior changes.

PowerShell and installer/package archives are local-only. Follow REPOSITORY-POLICY.md and run the repository policy check before proposing a push. Never commit personal configuration, databases, logs, credentials or real exported playlists.

Describe behavior changes and relevant validation. CI/release workflow changes need review. Signing credentials must never be exposed to untrusted contributions. The owner controls merge, release and signing decisions.

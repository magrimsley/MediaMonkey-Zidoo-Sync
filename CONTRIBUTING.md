# Contributing — draft

The license and public repository are undecided. This local candidate is not accepting externally contributed code yet. Select the license and contribution terms before inviting contributions.

Future changes should include a clear behavior description and relevant offline tests. Keep production sync disabled unless its enablement is a separately reviewed development task. Use disposable fixtures, reserved example addresses and synthetic playlist names. Never commit personal configuration, databases, logs, credentials or real exported playlists.

CI and release workflow changes require review because they control artifact provenance. Repository members and future signing approvers must use MFA. Signing credentials must not be provided to untrusted contributions.
